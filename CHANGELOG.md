# Changelog

## 1.3.0
- `safe-eject /dev/sdX` ejects a specific USB disk (used by the GNOME Shell extension).

## 1.2.0
- Add optional Nautilus right-click extension (`nautilus-extension/`), installed separately.

## 1.1.0
- Add `--help` and `--version`.
- Add Makefile (system-wide install), CI with ShellCheck, contribution docs.

## 1.0.0
- Initial release: quit Nautilus, sync, unmount, power off USB drives.
- English and Persian messages.
